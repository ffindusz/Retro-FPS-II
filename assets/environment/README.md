# Original fortress surfaces

Six original 512×512 RGB PNG images are authored offline by `tools/generate_fortress_assets.gd`, not downloaded or generated by a paid service. Each family has albedo and roughness maps:

| Family | Pattern in one tile | Seed | Purpose |
|---|---|---:|---|
| wall | 128×64px staggered blocks | 17 | Rough block-stone walls |
| floor | 256×256px staggered slabs | 29 | Flagstone floors |
| trim | 256×128px staggered blocks | 43 | Worn stone trim/pillars |

Periodic low-frequency variation, deterministic fine grain, seeded per-block colors, dark mortar and edge wear create the surfaces. The authoring script asserts staggered boundary wrapping. Mipmaps are enabled; StandardMaterial3D uses repeat sampling and world-aligned triplanar coordinates at `uv1_scale = (0.5, 0.5, 0.5)`, approximately two meters per image tile. Colors vary slightly by entrance/courtyard/crypt through shared cached materials. Iron/brass accents use shared solid-color rough metallic materials, not additional images.

Source image sizes/material mappings are tested; human seam/scale/readability approval remains separate. No Meshy source files, model normalization, actor materials or 1024px model texture limits are modified. These original procedural assets need no third-party texture attribution; the owner chooses the project's overall distribution license.
