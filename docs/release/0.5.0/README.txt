CINDERKEEP 0.5.0 - ANIMATED WARDEN WINDOWS PLAYTEST
================================================

Launch Cinderkeep.exe, keeping Cinderkeep.pck beside it. No editor, export
templates, .NET, account, installation or runtime network is required.
This is a separate build; the accepted 0.4.1 files remain unchanged.

CONTROLS
  WASD / mouse       Move / look
  Space              Jump
  Left mouse (hold)  Attack / repeat after recovery
  1 / 2              Iron Blade / Ember Staff
  E                  Interact with the nearby exit gate
  Escape             Pause / resume
  Tab or arrows      Navigate menus
  Enter or Space     Activate focused menu button

Pause offers independent SFX and Ambience volume/mute sliders, retained
across restarts in the current app session, not across app launches.

OBJECTIVE
Cross the courtyard, enter the crypt through the eastern opening, collect
the gold ember key, then return to the sealed northeast gate and press E.
Red/blue flasks restore health/arcana; full-resource flasks stay available.
Melee costs no mana. Eliminating every enemy is not required.
Use cover/movement or a lethal hit to stop a committed enemy attack;
nonlethal damage does not cancel its windup. Defeat/victory offer restart.

NEW IN 0.5.0
Four melee Wardens use the approved Brigandine body and Idle/Walk/Attack/
Hit/Death animations, plus the separate Iron Blade with a corrected palm
mount. Combat balance, actor placement, collision, navigation and objectives
are unchanged. Two Adepts retain their old static/ranged presentation.
Photographic stone, moonlit sky, dynamic lights and original audio remain.

KNOWN LIMITS / REVIEW
Open fingers do not wrap around the handle. Native foot sliding, airborne
poses and some body/weapon/floor intersections remain. No foot/finger IK.
Body+blade exceeds the original ~10k source-triangle guideline (11,376).
No save/load, multiplayer, music, controller support or general settings menu.
Technical source/package checks and native startup/menu rendering pass;
the corrected grip, integrated feel and complete offline native run still
need user review. Prior 0.4.1 approval is not approval of this new build.
